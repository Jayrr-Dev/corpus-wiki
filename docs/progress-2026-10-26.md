# Progress: 2026-10-26

What was done today, what is still running, and what is left. The working plans

## Done and on main

### Hybrid chat search (built; off until switched on)

- `search_units_text` (ranked keyword search, any word) and `linked_units` (one
  hop over live links). Migration `20261119026000_hybrid_search.sql`, **applied
  to the live database** through the Supabase connector and recorded under that
  version.
- `lib/chatbot/fusion.ts`: reciprocal rank fusion with a cap per list.
- `lib/chatbot/rank.ts`: `rankUnits` runs the arms (meaning, keyword, link,
  scoped meaning, scoped words), caps each at 20, fuses them, and reranks the top
  40 with Voyage when switched on. If the rerank fails, it falls back to the
  legacy order. `CHAT_SEARCH=legacy|hybrid` picks the mode (default legacy).
- `lib/ai/rerank.ts`: Voyage `rerank-2.5` client, on only with
  `CHAT_RERANKER=voyage` and `VOYAGE_API_KEY`.
- `evals/retrieval/`: 60 questions from live claims (10 scoped to an entity),
  a runner, and results. Three repeat runs gave the same scores.

| Mode | hit@5 | hit@10 | MRR | Median time |
|---|---|---|---|---|
| legacy (current default) | 90.0% | 96.7% | 0.804 | 257 ms |
| hybrid, no reranker | 53.3% | 73.3% | 0.477 | 405 ms |
| hybrid + Voyage | 98.3% | 98.3% | 0.902 | 796 ms |

A reranked search uses about 1,980 Voyage tokens: about $0.10 per 1,000
searches at list price. Hybrid must never run without the reranker.

### AI cost cuts

- **Decision roles moved to Haiku 5.5 (live).** Both spaces' `workspace_settings`
  pin deduplicator, reviewer, article_reviewer, domain_decider, domain_steward and
  curator to `anthropic/claude-haiku-5-5`. The reviewer had been on Sonnet in the
  Enneagram space. Composer stays on Opus.
- Check on that switch (`scripts/cost/review-notes.md`): Haiku and Sonnet agree
  on 77 of 78 fact-check lines; Haiku misses some repetition in section
  editorial review (31 lines flagged against Sonnet's 39); Haiku costs about 8%
  of Sonnet on the same work.
- **One Deduplicator role.** Glossary, entity, domain and topic-name duplicate
  checks now route to `deduplicator`, alongside the claim checks. Settings and the
  workflow page call it "Deduplicator".
- **NLI prefilter, on by default.** `lib/ai/nli.ts` runs
  `cross-encoder/nli-deberta-v3-base` locally (about 200 MB, downloaded on first
  use; on Vercel it is cached in the temp folder). `lib/dedup/prefilter.ts` drops
  only candidates that are unrelated in both directions; it never confirms a
  duplicate, because it mistakes swapped-word pairs for the same claim.
  `DEDUP_NLI=off` turns it off. **No duplicate check calls it yet**; see the
  glossary and claims lanes below.
- **Slimmer topic prompts, off by default.** `TOPIC_PROMPT_BUDGET=on` gives each
  batch only its own neighbours, references them instead of copying text, and
  splits oversized prompts. A size guard always logs topic prompts over 100k
  tokens. Prompts shrank 8 to 38% on real uploads with the same placements.
- **Cost report.** `scripts/cost/report.ts` prices `public.ai_calls` with
  `lib/ai/pricing.ts`, per purpose, role, model and upload. Baseline saved as
  `scripts/cost/baseline-2026-10-26.json`.

### What the money data showed (30 days)

- About $88 in total, almost all in bursts; the last 7 days cost $0.20.
- The main cause was one upload: a 461-page archetypes PDF in the Enneagram space
  on 2026-10-18. It created about 20 articles and 648 sections and triggered about
  4,500 reviewer calls. A normal upload causes a few to a few dozen reviewer calls
  (about 5 per section built).
- 265 calls (1.9%) went over Haiku's 100k-token long-context line and cost $22.52
  (25.6% of the total), mostly `place_topics` and
  `independent_upload_domain_review`.

# Landing page plan

Plan for the main marketing page (`/welcome`). Audience: **teams first**. Business teams are the primary reader; developer and agent sections sit lower on the page.

One offer, one action: **Start free**.

## Page order

1. **Navigation.** Floating bar: logo; Product, How it works, For agents, FAQ; Sign in; one "Start free" button.
2. **Hero: the live page (concept 7).** "Pages that rewrite themselves." A 3D paragraph card whose sentences rewrite as sources arrive, with the facts (KUs) each source becomes, a conflict question and a change log. One promise line under the button (needs real plan terms).
3. **Proof strip.** Real numbers or real customer logos only. Leave out until real proof exists.
4. **Problem.** "Your wiki was right the day you wrote it." Three pains: rules change but pages don't; teams keep different versions; nobody knows where a statement came from.
5. **Tagline reveal.** "Every fact knows where it came from. Every change knows what it touched." Word by word on scroll.
6. **How it works: the glass machine (concept 6).** Files feed in, a graph grows and sorts into labelled groups, outputs roll out (pages, articles, tutorials, glossary, client list, quizzes, stakeholders, visuals, agent context). Labels: Feed it, It updates, You check.
7. **What you get.** One section per core output, text alternating sides:
   - **Glossary (concept 8).** "One meaning for every term." Centered layout; keep as is.
   - **Dictionary (concept 9).** "Your team's dictionary, written by your files."
   - **Stakeholders (concept 12).** "Know who matters, and why." A map of people and organizations that rewires as sources arrive (new sponsor, new supplier, a changed reporting line), beside a stakeholder card with power level, links and sourced facts.
8. **Trust and control.** Every line has a source; risky changes wait for a person; every change can be undone; full change log.
9. **Use cases.** Process handbook, studying a big subject, project memory, rules and compliance, memory for AI agents (see `features.md`).
10. **For AI agents (concept 10).** "One memory for every agent." Claude, Cursor, ChatGPT and Gemini share one memory over MCP (`get_context`, `add_note`).
11. **For builders (concept 11).** "Just build. Docs write themselves." A week of coding in a generic terminal agent while a docs site fills in to 100%.
12. **Pricing preview and risk reversal.** "Free to start" and a link to plans (needs real terms).
13. **FAQ.** Six to ten plain questions; the current page has a start.
14. **Final call to action.** Same "Start free" as the hero.
15. **Footer.** Privacy, terms, contact, social.

## Open items

- **Glossary and dictionary overlap.** Two sections back to back, or one section with two tabs.
- **Proof.** No real quotes, logos or numbers yet.
- **Plan terms.** Free plan details for the hero promise and pricing preview.
- **Performance.** Six animated sections: run each animation only while it is on screen.

## Rules

- Built to the landing page design rules: Geist only, Tailwind type scale, the fixed spacing set, flat backgrounds, Phosphor icons, no hyphens in copy.
- Concepts 1 to 5 from the first rounds are dropped.
- Future outputs (articles, tutorials, quizzes, client list) are shown but never labelled as future.
- Mockups for concepts 6 to 12 were built as standalone HTML in a session scratchpad; rebuild from this plan if they are gone.
